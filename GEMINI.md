# Contexto del Proyecto: Tesis Mecatrónica UTEC 2026

Este proyecto cuenta con las directrices, especificaciones técnicas y contexto centralizados en:
- [`AGENTS.md`](./AGENTS.md) — Instrucciones maestras de proyecto, bitácora técnica y roles para agentes.
- [`CONTEXTO_TESIS.md`](./CONTEXTO_TESIS.md) — Base de conocimiento completa, especificaciones cuantitativas (ISO 29148), funciones de transferencia de control, arquitectura de hardware y cronograma de 16 semanas.
- [`docs/PROGRESO.md`](./docs/PROGRESO.md) — Estado de avance semanal (S13), hitos completados y siguientes pasos.
- [`docs/DECISIONES.md`](./docs/DECISIONES.md) — Registro de decisiones de arquitectura e ingeniería (ADR) para la memoria y defensa de tesis.
- [`firmware/CHANGELOG.md`](./firmware/CHANGELOG.md) — Trazabilidad de versiones de código y soluciones de hardware en ESP32/ESP32-S3.

Todos los agentes y sesiones de chat deben consultar estos archivos para mantener coherencia técnica y conceptual con el desarrollo del sistema robótico cooperativo para monitoreo en minería subterránea.
